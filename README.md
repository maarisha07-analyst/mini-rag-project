# Mini RAG Project

A "chat with your documents" tool using Retrieval-Augmented Generation (RAG).

## Status
🚧 In progress — learning project

## Tools
- sentence-transformers (embeddings)
- ChromaDB (vector storage)
- Built in Google Colab

## What it does
Takes a set of documents, lets you ask natural-language questions, and retrieves grounded answers from the actual content instead of relying on the model's memory.
